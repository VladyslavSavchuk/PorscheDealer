## About

**PORSCHE** is a team university project developed for **Laboratory Work #2 at Lviv Polytechnic**.

The goal was to create a modern **Porsche dealer website concept in Lviv** with a premium visual style, clear navigation and realistic dealership functionality.

The website includes:

- Porsche models
- Available vehicles
- Service information
- About the dealership
- Test-drive requests
- Contacts and location

> This is an educational project and is not affiliated with or endorsed by Porsche AG.

### Brainstorm

The project started with a simple idea:

> **"What would a modern Porsche dealer website look like if we designed it from scratch?"**

The team focused on three main areas:

**Brand** → premium, minimal, automotive  
**UX** → simple navigation and accessible information  
**Development** → a real React application with deployment workflow
